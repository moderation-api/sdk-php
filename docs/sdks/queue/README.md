# Queue

## Overview

### Available Operations

* [list](#list) - List queues
* [retrieve](#retrieve) - Get a queue
* [getStats](#getstats) - Get queue statistics

## list

List the review queues of the project. The default queue comes first. The list is paginated. To get the item counts of a queue, use `GET /queue/{id}`.

### Example Usage

<!-- UsageSnippet language="php" operationID="listQueues" method="get" path="/queue" -->
```php
declare(strict_types=1);

require 'vendor/autoload.php';

use ModerationApi;

$sdk = ModerationApi\ModerationApi::builder()
    ->setSecurity(
        '<YOUR_BEARER_TOKEN_HERE>'
    )
    ->build();



$responses = $sdk->queue->list(
    page: 1,
    pageSize: 20

);


foreach ($responses as $response) {
    if ($response->statusCode === 200) {
        // handle response
    }
}
```

## getStats

Get review statistics of a queue for a period: resolved and pending items, the top reviewers and the resolved items per day.

### Example Usage

<!-- UsageSnippet language="php" operationID="getQueueStats" method="get" path="/queue/{id}/stats" -->
```php
declare(strict_types=1);

require 'vendor/autoload.php';

use ModerationApi;

$sdk = ModerationApi\ModerationApi::builder()
    ->setSecurity(
        '<YOUR_BEARER_TOKEN_HERE>'
    )
    ->build();



$response = $sdk->queue->getStats(
    id: '<id>',
    withinDays: 30

);

if ($response->object !== null) {
    // handle response
}
```
