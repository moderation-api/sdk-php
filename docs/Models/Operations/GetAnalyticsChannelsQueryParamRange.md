# GetAnalyticsChannelsQueryParamRange

The time window. `24h` is the last 24 hours, in hourly buckets. `7d`, `30d` and `90d` are whole UTC days that end with today, in daily buckets.


## Values

| Name          | Value         |
| ------------- | ------------- |
| `TwentyFourh` | 24h           |
| `Sevend`      | 7d            |
| `Thirtyd`     | 30d           |
| `Ninetyd`     | 90d           |
