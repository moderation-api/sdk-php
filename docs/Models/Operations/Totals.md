# Totals

Request counts for the window. A flagged request has one recommendation: allow, reject or review.


## Fields

| Field                                                                                                            | Type                                                                                                             | Required                                                                                                         | Description                                                                                                      |
| ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `requests`                                                                                                       | *int*                                                                                                            | :heavy_check_mark:                                                                                               | Requests received. Every request counts, also repeats and edits of the same content.                             |
| `flagged`                                                                                                        | *int*                                                                                                            | :heavy_check_mark:                                                                                               | Requests that were flagged.                                                                                      |
| `flagRate`                                                                                                       | *float*                                                                                                          | :heavy_check_mark:                                                                                               | The share of requests that were flagged: flagged / requests. 0 when there were no requests.                      |
| `allowed`                                                                                                        | *int*                                                                                                            | :heavy_check_mark:                                                                                               | Requests with the recommendation "allow". Includes content that was not flagged.                                 |
| `rejected`                                                                                                       | *int*                                                                                                            | :heavy_check_mark:                                                                                               | Requests with the recommendation "reject". All of them were flagged.                                             |
| `sentToReview`                                                                                                   | *int*                                                                                                            | :heavy_check_mark:                                                                                               | Requests with the recommendation "review". This counts requests, not the deduplicated items in the review queue. |
| `handledAutomatically`                                                                                           | *int*                                                                                                            | :heavy_check_mark:                                                                                               | Flagged requests that were settled without human review: rejected plus flaggedButAllowed.                        |
| `flaggedButAllowed`                                                                                              | *int*                                                                                                            | :heavy_check_mark:                                                                                               | Flagged requests that were allowed without human review.                                                         |
| `distinctAuthors`                                                                                                | *int*                                                                                                            | :heavy_check_mark:                                                                                               | Distinct authors that sent content in the window. Approximate.                                                   |
